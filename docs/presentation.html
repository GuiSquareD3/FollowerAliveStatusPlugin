TurboHUD plugin · Diablo III

Follower Alive Status

A skull on your HUD that turns red the moment your follower goes down, green when they get back up, and grey when you have no follower hired — with a counter that tallies their deaths and never yours.

What it reads

Two independent signals, and a deliberately asymmetric rule between them: the follower counts as alive if either source says alive, and dead only when both agree. A missing read can never manufacture a death.

SignalRole
IActor.Hitpoints Primary. Verified in game as current health: it drops to 0 on death while the actor stays present, then climbs back on revival.
Hitpoints_Cur Secondary. This attribute is not exposed on follower actors — it returns -1 — so it only ever confirms life, never death.
Actor SNO Strict match on the three hired hirelings: _hireling_templar (52693), _hireling_scoundrel (52694), _hireling_enchantress (4482). The town NPC versions carry different SNOs and are ignored.
Pet item slots Follower gear in PetRightHand…PetBracers proves a follower is hired even at a moment the actor is not loaded.

What it refuses to count

Every guard below exists to keep one number honest. A death is only ever recorded after the plugin has confirmed the follower alive first — so an ambiguous moment costs you a missed count at worst, never a phantom one.

SituationBehaviour
Your hero diesState frozen, counting suspended, plus a 3 s blind window after you resurrect.
Loading screen, menu, pausedGrey, detection disarmed.
Zone change, rift entry, town portal4 s blind window; the follower must be seen alive again before a death can register.
Fast teleport chainsNothing. Death rests on hitpoints alone — a briefly uncollected actor is treated as a gap, not a corpse.
Multiplayer gameGrey. Followers cannot be brought along.
Standing beside the town follower NPCsGrey. Their SNOs do not match a hired hireling.

Where it sits

By default the icon docks under the RBH session panel. RBH draws that panel from the top-left corner of the minimap element downwards, and its internals are private, so the plugin anchors to the same element and drops by a ratio you can tune — no RBH code is touched or required.

Install

  1. Drop the folder in

    Copy GuiSquare into your TurboHUD plugins directory. The plugin is self-contained — no other files, no textures.

  2. Whitelist it if you run RBH

    RBH's plugin manager disables everything it does not know about. Add one line to Manager_Config.cs, in the Enable_Plugins list:

    "Turbo.Plugins.GuiSquare.FollowerAliveStatusPlugin"

  3. Line it up

    Restart TurboHUD. If the skull overlaps the session panel or floats too low, nudge a single number — RbhPanelHeightRatio, which depends on how many tracker lines you have enabled. A companion customizer file exposes that and every other option without editing the plugin.

Verified in game

Each case below was walked through live, with a diagnostic panel reading the raw signals. The panel ships with the plugin and can be switched back on at any time.

  • Follower alive
  • Follower death counted once
  • Revival, no double count
  • Your own death, counter frozen
  • Follower dismissed, NPCs in range
  • Fast teleport chains
The counter runs session-wide by default and can be reset per game. Icon style, size, colours, position, an optional spoken alert on death, and the diagnostic panel are all reachable from the customizer file.
